Revision 1.1.0 fixes known bugs of the initial 1.0.0 revision. Main changes includes:
* Fix signal directions for JTAG signal buffers
* Reduce RGB LED intensity
* Fix UART cross to `FT4232H`
* Replace RTC battery socket, set as DNP
* Fix U21 PG LED
* Optimize BOM
* Disconnect MCU from FT4232H reset, set as DNP
